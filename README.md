# Grammar Connection Using NLP

## Description
This project uses Natural Language Processing (NLP) to analyze a sentence and identify the grammatical tags of each word.

## Technologies Used
- Python
- NLTK (Natural Language Toolkit)

## Features
- Takes a sentence as input
- Tokenizes the sentence into words
- Identifies the Part-of-Speech (POS) tag of each word
- Displays the word and its grammatical tag

## How to Run
1. Install Python.
2. Install NLTK using:
   pip install nltk
3. Run the Python file:
   python grammar_nlp.py
